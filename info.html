INFORMAÇÕES

O ASTRONAVEGA utiliza imagens e dados de domínio público da NASA para criar uma experiência espacial educativa e imersiva.

SOBRE A API DA NASA

A NASA disponibiliza várias APIs públicas e gratuitas para desenvolvedores:

  • APOD — Astronomy Picture of the Day
  • Mars Rover Photos — Fotos dos rovers em Marte
  • EPIC — Earth Polychromatic Imaging Camera
  • NeoWs — Near Earth Object Web Service
  • NASA Image and Video Library

COMO OBTER UMA CHAVE API

Podes registar-te gratuitamente em:

https://api.nasa.gov/

  • Explora o mundo e aprende jogando!
